# STRIDE MB — Manhattan Beach Sneaker Boutique Template

A luxury e-commerce and streetwear template built for high-end boutique storefronts, Webflow creators, and agencies.

## 📁 File Structure

* `index.html` — Homepage featuring the drop countdown, featured drops bento grid, and lookbook tease.
* `shop.html` — Product catalog with category filter tabs and sort controls.
* `product-detail.html` — Luxury product detail page with size selectors and accordion specifications.
* `drops.html` — Upcoming releases and sole raffle entry forms.
* `lookbook.html` — High-fashion coastal editorial story.
* `about.html` — Manhattan Beach flagship story and authentication pillars.
* `contact.html` — VIP concierge booking and store location details.
* `styleguide.html` — Typography, palette, buttons, and component design system.
* `webflow-cms-schema.json` — Pre-configured CMS collections for Webflow.
* `assets/css/style.css` — Custom glassmorphism, animations, and typography styles.
* `assets/js/app.js` — Live countdown timer, slide-out cart drawer, and interactive size selectors.
* `gumroad-listing-kit/product-description.md` — Ready-to-use Gumroad listing sales copy.

## 🚀 How to Preview Locally

Open `index.html` in any modern web browser or serve via a local HTTP server:
```bash
npx serve .
```
